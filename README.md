# «почка» — портал о здоровье почек · фонд «Настенька»

Рабочий HTML-прототип двухуровневого портала («айсберг»):

- **Верхушка** (`index.html`) — массовый экспертный портал о здоровье почек для широкой аудитории: как работают почки, минутный чек-ап, диализ и пересадка простыми словами, истории людей, фандрайзинг.
- **Подводная часть** (`parents.html`) — детальный навигатор для родителей детей с болезнями почек: маршруты лечения, каталог клиник, права и документы, база знаний, сообщество.

## Воронка между уровнями

- Каждая тема массового портала содержит блок «Это про вашего ребёнка?» → переход в навигатор.
- Родители из больниц попадают сразу в навигатор по QR-коду (`start.html`).
- В шапке обеих зон — перекрёстные ссылки («Родителям» / «Основной портал»).

## Технологии

Чистые HTML + CSS + ванильный JS, без сборщиков. Работает со статического хостинга.

- Шрифты: Manrope, Literata, Caveat (Google Fonts)
- Адаптив, анимации с поддержкой `prefers-reduced-motion`
- Интерактив: мини-тест, фильтры клиник, степпер маршрута, чек-лист (localStorage), FAQ, табы

## Статус

**Прототип.** Данные о клиниках, контакты и цифры — демонстрационные, перед запуском проверяются с учреждениями. Материалы не заменяют консультацию врача.
