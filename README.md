# «почка» — портал о здоровье почек · фонд «Настенька»

Рабочий HTML-прототип портала с тремя понятными входами и одной глубокой зоной для семей.

## Три аудитории

| Аудитория | Что получает | Вход |
| --- | --- | --- |
| Широкая аудитория / ЗОЖ | Простое объяснение почек, расшифровка анализов, привычки, мифы, быстрые проверки | `index.html` → `health.html` |
| Группы риска (взрослые) | Давление, диабет, наследственность; чек-лист и тест рисков; калькулятор СКФ | `risk.html`, `services.html` |
| Родители детей с ХБП 3–5 | Маршруты лечения, каталог медучреждений, документы, знания, опыт семей | `parents.html` и его разделы |

Публичные страницы не объясняют внутреннюю структуру: переходы между входами сделаны полезными ссылками, блоками «Это про вашего ребёнка?» и QR-страницей из медучреждений.

> **`concept.html`** — внутренняя схема для команды и заказчика (`noindex`, с публичных страниц нет ссылок).

## Технологии

Чистые HTML + CSS + ванильный JS, без сборщиков. Работает со статического хостинга.

- Шрифты: Manrope, Literata, Caveat (Google Fonts)
- Адаптив, анимации с поддержкой `prefers-reduced-motion`
- Интерактив: фильтры каталога, степпер маршрута, чек-лист с `localStorage`, калькулятор СКФ, тест рисков, поиск по продуктам и порталу

## Статус

**Прототип.** Данные о клиниках, контакты, цифры и расчёты — демонстрационные; перед запуском проверяются с учреждениями и врачами. Материалы не заменяют консультацию врача.
