# «почка» — портал о здоровье почек · фонд «Настенька»

Рабочий HTML-прототип двухуровневого портала:

- **`index.html`** — массовый экспертный портал о здоровье почек для широкой аудитории: как работают почки, минутный чек-ап, диализ и пересадка простыми словами, истории людей, фандрайзинг.
- **`parents.html`** — навигатор для родителей детей с болезнями почек: маршруты лечения, каталог клиник, права и документы, база знаний, сообщество.

Пользователю уровни не «объясняются»: они связаны незаметно — кнопкой «Родителям» в шапке, блоками «Это про вашего ребёнка?» в статьях и QR-кодами из больниц.

> **`concept.html`** — внутренняя страница-схема двух уровней для обсуждений с командой и заказчиком (`noindex`, с публичных страниц на неё нет ссылок).

## Страницы

| Файл | Уровень | Страница |
| --- | --- | --- |
| `index.html` | массовый | Главная: чек-ап (интерактивный тест), как работают почки, диализ/пересадка, истории, помочь фонду |
| `parents.html` | навигатор | Главная навигатора: выбор ситуации, метро-маршрут, клиники, маршруты, истории, сообщество |
| `clinics.html` | навигатор | Каталог клиник с рабочими фильтрами |
| `clinic-card.html` | навигатор | Карточка центра: паспорт, «как попасть», быт, опыт семей |
| `routes.html` | навигатор | Список маршрутов получения помощи |
| `route.html` | навигатор | Интерактивный маршрут: степпер с прогрессом, чек-лист перед поездкой (сохраняется в браузере) |
| `rights.html` | навигатор | Права и документы: 057/у, ВМП, инвалидность, лекарства, проезд и жильё |
| `knowledge.html` | навигатор | База знаний: первые шаги, диагнозы, диализ, трансплантация, питание, профилактика |
| `community.html` | навигатор | Сообщество и фонд: чат «Пересадка», психологи, помощь, истории |
| `start.html` | вход | QR-лендинг из памяток в больницах |
| `concept.html` | внутреннее | Схема двух уровней портала (для команды и заказчика, noindex) |

## Технологии

Чистые HTML + CSS + ванильный JS, без сборщиков. Работает со статического хостинга.

- Шрифты: Manrope, Literata, Caveat (Google Fonts)
- Адаптив, анимации с поддержкой `prefers-reduced-motion`
- Интерактив: мини-тест, фильтры клиник, степпер маршрута, чек-лист (localStorage), FAQ, табы

## Статус

**Прототип.** Данные о клиниках, контакты и цифры — демонстрационные, перед запуском проверяются с учреждениями. Материалы не заменяют консультацию врача.
