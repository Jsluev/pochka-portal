# «почка» — информационный портал для семей с детьми с болезнями почек

Рабочий HTML-прототип портала благотворительного фонда «Настенька».

Портал отвечает на три главных вопроса родителей (по исследованию фонда — 13 130 запросов в чате «Пересадка» за 2025 год):

1. **Куда обращаться?** — каталог клиник и центров с фильтрами.
2. **Как туда попасть?** — пошаговые маршруты получения медпомощи.
3. **Что для этого нужно?** — права, документы, льготы, чек-листы.

## Структура

| Файл | Страница |
| --- | --- |
| `index.html` | Главная: герой-блок, выбор ситуации, метро-маршрут, клиники, маршруты, истории, сообщество |
| `clinics.html` | Каталог клиник с рабочими фильтрами (тип, город, вид помощи, возраст, поиск) |
| `clinic-card.html` | Карточка центра: паспорт, «как попасть», быт, опыт семей |
| `routes.html` | Список маршрутов получения помощи |
| `route.html` | Интерактивный маршрут «Из региона в федеральный центр»: степпер с прогрессом, чек-лист перед поездкой (сохраняется в браузере) |
| `rights.html` | Права и документы: 057/у, ВМП, инвалидность, лекарства, проезд и жильё |
| `knowledge.html` | База знаний: первые шаги, диагнозы, диализ, трансплантация, питание (вкладки по этапам), профилактика |
| `community.html` | Сообщество и фонд: чат «Пересадка», психологи, адресная помощь, истории |
| `start.html` | Целевая страница для QR-кодов из памяток |

## Технологии

Чистые HTML + CSS + ванильный JS, без сборщиков и зависимостей. Работает и с локального файла, и с любого статического хостинга.

- Шрифты: Manrope, Literata, Caveat (Google Fonts)
- Адаптив: бургер-меню, мобильные сетки
- Анимации с fallback и поддержкой `prefers-reduced-motion`

## Статус

**Прототип.** Данные о клиниках, контакты и цифры — демонстрационные, перед запуском проверяются с учреждениями. Медицинская информация не заменяет консультацию врача.
